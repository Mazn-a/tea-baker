# إعداد شاي بكر — خطوة بخطوة

## أولاً: ربط قاعدة البيانات (مرة واحدة)

1. ادخل [supabase.com](https://supabase.com) وأنشئ مشروعاً مجانياً.
2. من **Project Settings → API** انسخ:
   - `Project URL`
   - `anon public key`
3. الصقهما في `js/config.js`:

```js
window.BAKR_CONFIG = {
  supabaseUrl: "https://xxxx.supabase.co",
  supabaseAnonKey: "sb_publishable_xxxx",
  ...
};
```

4. من **SQL Editor → New query** الصق محتوى `sql/schema.sql` كامل واضغط **Run**.

افتح لوحة الإدارة: إذا صارت النقطة على الشعار **خضراء** فالربط تمّ.

---

## ثانياً: حماية بيانات العملاء (مهم جداً قبل نشر الرابط)

بدون هذه الخطوة، أي شخص يفتح كود الموقع يقدر يقرأ **أسماء وأرقام جوالات كل عملائك**،
لأن مفتاح الموقع العام موجود داخل الصفحة والصلاحيات مفتوحة للجميع.

### 1) أنشئ حساب دخول للإدارة

Supabase → **Authentication** → **Users** → **Add user** → **Create new user**

- البريد: أي بريد تستخدمه للدخول (مثل `admin@teabakr.com`)
- كلمة المرور: قوية واحفظها
- فعّل **Auto Confirm User** حتى تدخل مباشرة بدون تأكيد بريد

كرّر الخطوة لكل شخص تبيه يدخل اللوحة — كل واحد بحسابه.

### 2) نفّذ ملف الحماية

SQL Editor → New query → الصق محتوى `sql/patch-secure-admin.sql` → **Run**

بعد التنفيذ:

- الزائر يقدر **يرسل طلباً** ويشوف **التواريخ المحجوزة فقط**
- قراءة الطلبات وتعديلها وحذفها **للمسجّلين دخول فقط**
- الطلب المحذوف يُمسح من الجدول نهائياً

### 3) أقفل الدخول بالرمز

في `js/config.js` غيّر:

```js
adminAuth: "supabase",
```

من هذه اللحظة يختفي خيار «الدخول برمز مؤقت» ولا يفتح اللوحة إلا بريد وكلمة مرور.

### 4) تأكد أن كل شيء تمام

- افتح لوحة الإدارة وسجّل الدخول بالبريد وكلمة المرور
- الجلسة تبقى محفوظة، فلا يعيد الدخول كل مرة
- افتح الموقع من جوال آخر: التواريخ المحجوزة تظهر والطلب يُرسل عادي

---

## نصائح

- **نسيت كلمة المرور؟** Supabase → Authentication → Users → اضغط على المستخدم → Reset password.
- **تبي توقف موظفاً؟** احذف حسابه من نفس الصفحة، ينقطع دخوله فوراً.
- **نسخة احتياطية؟** من صفحة الطلبات اضغط **تصدير Excel** بين فترة وأخرى.
- بعد أي تعديل على ملفات CSS أو JS ارفع رقم النسخة في `index.html` (مثل `?v=70` → `?v=71`).
