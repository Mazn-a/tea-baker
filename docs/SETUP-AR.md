# إعداد قاعدة البيانات (تكلفة صفر) — خطوة بخطوة

نستخدم **Supabase Free** (بدون دفع). أنت تنشئ الحساب مرة واحدة، والموقع يتصل به.

## ماذا ستحصل؟
- جدول `orders` لكل الطلبات
- جدول `visits` لزيارات الموقع
- جدول `app_settings` للتوسعة لاحقاً
- ربط دائم بين رابط العملاء ورابط الإدارة من أي جهاز

---

## الخطوة 1 — إنشاء حساب ومشروع
1. افتح: https://supabase.com
2. Sign up (مجاناً — GitHub أو الإيميل)
3. **New project**
4. اختر اسماً مثل `shai-bakr`
5. ضع Database Password قوي واحفظه عندك
6. Region قريبة (مثل Frankfurt أو أي متاح)
7. Create project وانتظر دقيقة حتى يصبح Ready

## الخطوة 2 — إنشاء الجداول
1. من القائمة: **SQL → SQL Editor**
2. New query
3. افتح ملف المشروع: `sql/schema.sql`
4. انسخ **كل** المحتوى والصقه
5. اضغط **Run**
6. المفروض تظهر Success

للتحقق: من **Table Editor** يجب أن ترى جداول:
- `orders`
- `visits`
- `app_settings`

## الخطوة 3 — نسخ المفاتيح
1. **Project Settings → API**
2. انسخ:
   - **Project URL**
   - **anon public** key
3. افتح الملف في المشروع: `js/config.js`
4. الصق هكذا:

```js
window.BAKR_CONFIG = {
  supabaseUrl: "https://xxxxx.supabase.co",
  supabaseAnonKey: "eyJhbGciOi...",
  adminPin: "رمز-قوي-خاص-بك",
  waNumber: "966533508361",
};
```

5. احفظ الملف وحدّث المتصفح

## الخطوة 4 — التأكد من الربط
1. افتح الإدارة: http://127.0.0.1:8790/admin/
2. ادخل بالرمز
3. الشارة أعلى الصفحة يجب أن تصبح **سحابة**
4. صندوق حالة الربط يقول: متصل بقاعدة البيانات

ثم:
1. من موقع العملاء أرسل طلب تجريبي
2. من الإدارة (حتى من جهاز آخر) يظهر الطلب
3. اضغط قبول + واتساب أو رفض + واتساب

---

## هل التكلفة صفر فعلاً؟
- Supabase Free: مجاني لبداية المشاريع (حدود سخية للـ MVP)
- استضافة الموقع: GitHub Pages مجاناً أو أي استضافة ثابتة
- لا يوجد سيرفر خاص تدفع عليه الآن

عند النمو الكبير لاحقاً يمكن الترقية — لكن للانطلاق الحالي الخطة المجانية كافية.

## مشاكل شائعة
| المشكلة | الحل |
|---------|------|
| الشارة تبقى «محلي» | تأكد أن `config.js` فيه URL و Key صحيحين ثم Hard Refresh |
| خطأ عن جدول غير موجود | أعد تشغيل `schema.sql` |
| الطلب ما يظهر من جهاز ثاني | يعني لسه على الوضع المحلي — أكمل خطوات السحابة |
