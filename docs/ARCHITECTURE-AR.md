# معمارية المشروع — للتطوير لاحقاً

## التدفق
```
العميل (index.html + app.js)
   → store.js.createOrder()
      → Supabase.orders   أو   localStorage
         → لوحة الإدارة تقرأ listOrders()
            → قبول/رفض + واتساب لرقم العميل
```

## طبقات الكود
1. **catalog.js** — بيانات العمل فقط (أسعار، بكجات…)
2. **config.js** — أسرار التشغيل (مفاتيح، رمز إدارة)
3. **store.js** — كل القراءة/الكتابة للبيانات
4. **app.js / admin.js** — واجهات فقط، بدون تكرار بيانات

## إضافة بكج جديد
عدّل `js/catalog.js` → أضف عنصر داخل `packages` بنفس الحقول.

## إضافة جدول سحابي جديد (مثال: مدفوعات)
1. أضف `create table` في `sql/schema.sql` ونفّذه في SQL Editor
2. أضف دوال في `store.js` مثل `createPayment` / `listPayments`
3. استدعِها من `admin.js` أو `app.js`
4. لا تضع مفاتيح أو منطق تخزين داخل ملفات الواجهة

## حالات الطلب
- `pending` جديد
- `accepted` مقبول
- `rejected` مرفوض

## الوضعان
- **local**: تجريبي على نفس المتصفح
- **cloud**: تشغيل حقيقي مرتبط بين كل الأجهزة
