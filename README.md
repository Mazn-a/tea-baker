# شاي بكر — موقع الحجوزات + لوحة الإدارة

موقع عملاء بخطوات حجز بسيطة، ولوحة إدارة لقبول الطلبات ورفضها ومتابعة الزوار والدخل.

- الموقع: <https://mazn-a.github.io/tea-baker/>
- الإدارة: <https://mazn-a.github.io/tea-baker/admin/>
- رمز الإدارة: `1234` (غيّره من `js/config.js`)

## أين تعدّل ماذا؟

| تريد تعديل | الملف | السطر تقريباً |
|-----------|--------|----------|
| سعر بكج / إضافة بكج أو إضافة جديدة | `js/catalog.js` | `packages` و `addons` |
| كود الخصم | `js/catalog.js` | `discountCode` |
| رقم واتساب | `js/catalog.js` | `waNumber` |
| رمز دخول الإدارة | `js/config.js` | `adminPin` |
| ربط قاعدة البيانات | `js/config.js` | `supabaseUrl` / `supabaseAnonKey` |
| نصوص الصفحة والأسئلة الشائعة | `index.html` | — |
| صورة معاينة الرابط عند المشاركة | `assets/og-cover.jpg` + وسوم `og:` في `index.html` | — |
| شكل الجداول في السحابة | `sql/schema.sql` | — |

> بعد أي تعديل على ملف CSS أو JS، ارفع رقم النسخة في الرابط داخل `index.html`
> (مثل `styles.css?v=67` → `?v=68`) حتى يرى الزوار التحديث بدون تحديث يدوي.

## هيكل المشروع

```
tea-baker/
├── index.html              ← موقع العملاء
├── css/styles.css          ← ستايل العملاء (قواعد الجوال في آخر الملف)
├── js/
│   ├── catalog.js          ← الأسعار والبكجات والمدن وكود الخصم
│   ├── config.js           ← مفاتيح Supabase + رمز الإدارة
│   ├── store.js            ← حفظ الطلبات والزيارات (سحابة أو محلي)
│   └── app.js              ← منطق الحجز وواجهة العملاء
├── admin/                  ← لوحة الإدارة (طلبات · زوار · إحصائيات)
├── assets/                 ← الصور (مضغوطة — لا ترفع صوراً كبيرة)
├── sql/schema.sql          ← إنشاء جداول قاعدة البيانات
└── docs/                   ← خطوات الإعداد وكيف تضيف ميزة
```

## قبل نشر الرابط للناس

1. تأكد أن مفاتيح Supabase مضبوطة في `js/config.js` — بدونها **الطلبات لا تصل للإدارة**.
2. افتح اللوحة وتأكد أن النقطة على الشعار **خضراء** (متصل بقاعدة البيانات).
3. أرسل طلباً تجريبياً من جوالك، تأكد أنه ظهر في «الطلبات»، ثم احذفه.
4. جرّب الرابط في واتساب وتأكد أن صورة المعاينة تظهر.
5. نفّذ `sql/patch-delete-orders.sql` مرة واحدة إن أردت أن يُمسح الطلب المحذوف من الجدول نهائياً.

## كيف يعمل الحجز؟

- التاريخ يُحجز فور إرسال الطلب (قبل القبول) حتى لا يطلبه شخص آخر.
- الرفض أو الحذف يحرّر التاريخ تلقائياً.
- الحجز متاح حتى 12 شهراً قادمة فقط.
- إذا فشل الاتصال بقاعدة البيانات وقت الإرسال، يظهر للعميل زر «إرسال الطلب عبر واتساب» حتى لا يضيع الطلب.

## لوحة الإدارة

- **الطلبات**: كل طلب بلون حسب حالته، وبداخله كل التفاصيل مع أزرار القبول والرفض وإرسال PDF والحذف.
- **زوار الموقع**: كم شخص فتح الموقع اليوم / آخر ٧ أيام / آخر ٣٠ يوم، وكم منهم أرسل طلباً.
- **الإحصائيات**: الدخل وأوقات الذروة وأكثر المدن والبكجات طلباً.

