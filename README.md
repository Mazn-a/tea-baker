# شاي بكر — موقع الحجوزات + لوحة الإدارة


## الروابط المحلية
- العملاء: http://127.0.0.1:8790/
- الإدارة: http://127.0.0.1:8790/admin/
- رمز الإدارة الافتراضي: `1234` (غيّره من `js/config.js`)

## هيكل المشروع (واضح للتعديل)

```
tea/
├── index.html              ← موقع العملاء
├── admin/                  ← لوحة الإدارة
├── css/styles.css          ← ستايل العملاء
├── js/
│   ├── catalog.js          ← عدّل هنا: أسعار، بكجات، مدن، إضافات
│   ├── config.js           ← مفاتيح Supabase + رمز الإدارة
│   ├── store.js            ← حفظ الطلبات/الزيارات (سحابة أو محلي)
│   └── app.js              ← منطق الحجز وواجهة العملاء
├── sql/schema.sql          ← أنشئ به جداول قاعدة البيانات
├── data/booked-dates.json  ← تواريخ محجوزة يدوياً (اختياري)
├── docs/SETUP-AR.md        ← خطوات إنشاء الحساب وقاعدة البيانات
└── docs/ARCHITECTURE-AR.md ← كيف تضيف ميزة/جدول جديد
```

## أين تعدّل ماذا؟
| تريد تعديل | الملف |
|-----------|--------|
| سعر بكج / إضافة بكج جديد | `js/catalog.js` |
| رقم واتساب | `js/catalog.js` أو `js/config.js` |
| ربط قاعدة البيانات | `js/config.js` |
| شكل الجداول في السحابة | `sql/schema.sql` |
| نصوص/أقسام الصفحة | `index.html` |
| قبول/رفض/إحصائيات | `admin/js/admin.js` |

## التشغيل الحقيقي (مهم)
بدون مفاتيح السحابة: الطلبات تظهر فقط على **نفس المتصفح**.  
مع Supabase Free: أي جوال ↔ أي جهاز إدارة.  
اتبع: [`docs/SETUP-AR.md`](docs/SETUP-AR.md)
